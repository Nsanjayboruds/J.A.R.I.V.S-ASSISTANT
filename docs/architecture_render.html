Client Layer
Frontend UI
Cyberpunk Arc Reactor HUD Tailwind v4
Dynamic reactive visualizer, rotating tick rings, audio pulse glow, and manual code editor output.
3D WebGL Particle Galaxy OGL Engine
GPU-accelerated particle vortex reacting to mouse velocity and user presence.
Real-Time Facial Emotion AI face-api.js
In-browser neural net scanning webcam feed with 5-frame smoothing for jitter-free emotion tracking.
Multilingual Voice Input Web Speech STT
Continuous speech recognition with multi-language detection (EN, HI, MR, ES, FR, JA).
Neural Audio Player HTML5 Audio
Streams high-fidelity base64 MP3 generated from backend neural voice pipelines.
⚙️
Backend Layer
Express Engine
API Gateway & Routers Express 5
Central routing for /auth, /user, /project, /vision, /voice, /emotion, and /command.
JWT Auth & Cookie Guard Bcrypt + JWT
Secures assistant endpoints, maintains encrypted session cookies and user identity.
Workspace Project Analyzer fs + AST
Recursively indexes files, detects frameworks (React, Next, Express), and extracts prompt context.
OS Automation Executor child_process
Executes authorized host bash commands (launches VS Code, runs dev servers, terminal tasks).
Phonetic Voice Router PronounceDict
Translates dev acronyms ("API", "GPU", "React") to regional phonetics for natural Hindi/Marathi TTS.
Desktop Screen Capture screenshot-desktop
Grabs active desktop display buffers and feeds them to the Vision LLM for UI debugging.
☁️
AI & Cloud Services
Cognitive Layer
Groq LLaMA 3.3 70B Fast LPUs
Sub-second reasoning, strict structured JSON intent generation, and adaptive emotional persona.
Groq LLaMA 3.2 11B Vision Multimodal
Inspects screenshots to summarize active windows, error traces, and IDE layouts.
Microsoft Edge Neural TTS node-edge-tts
Generates human-grade speech in English (Andrew), Hindi (Swara), and Marathi (Aarohi).
Media & Avatars Cloudinary + Replicate
Asset CDN for custom assistant avatars and on-demand SDXL AI image synthesis.
🗄️
Persistence Layer
MongoDB Database
User Profiles & Credentials Mongoose
Stores user accounts, hashed passwords, assistant preferences, and Cloudinary avatar links.
RAG Session Memory & History Context Cache
Retains multi-turn conversation logs and emotional trend metrics across developer sessions.
